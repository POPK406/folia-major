The module is a flat collection of platform-specific packaging artifacts with no shared runtime code:
- `aur/folia-major-bin/` — an AUR PKGBUILD that downloads a prebuilt tarball from GitHub Releases and installs it under `/opt/folia-major`, symlinking into `/usr/bin` alongside `.desktop` and icon files.
- `linux/build-windowtolayer.mjs` — a Node build script that clones a pinned revision of the upstream `windowtolayer` project, applies two bundled patches from `linux/patches/`, builds it with Cargo, and copies the binary plus its GPL-3.0 COPYING into `build/`; it is a no-op on non-Linux hosts and serves as the single source of truth for both local `npm run build:electron*` and CI.
- `windows/wallpaper-helper/` — a standalone Rust crate (`folia-wallpaper-helper`) built via `cargo build --release` by `windows/build-wallpaper-helper.mjs`; uses `cfg(windows)` target-gating so the crate compiles on non-Windows hosts for lint/test, and produces `folia-wallpaper-helper.exe` placed in `build/` for electron-builder's `extraResources`.
- `ffmpeg/fetch-ffmpeg.mjs` — exports `prepareBundledFfmpeg` / `resolveFfmpegAsset` which download one of five pinned FFmpeg release archives (linux-x64/arm64, mac-x64/arm64, win-x64) from `chthollyphile/folia-ffmpeg-build`, verify SHA-256, extract only the runtime binary plus `share/folia-ffmpeg`, and cache via a `BUNDLE-INFO.txt` marker file.
Dependency direction is one-way: these scripts are invoked by the top-level build to populate `build/`, which the Electron main process then consumes at runtime.
