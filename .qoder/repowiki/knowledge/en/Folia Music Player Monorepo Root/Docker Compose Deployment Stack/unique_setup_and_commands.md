Production deploy requires only `compose.yaml` + `.env` downloaded into an empty directory; generate `SYNC_TOKEN` via `openssl rand -hex 32`. Local smoke test: `FOLIA_IMAGE_NAMESPACE=folia-local SYNC_TOKEN=docker-check-token docker compose -f deploy/docker/compose.yaml -f deploy/docker/compose.build.yaml build && ./deploy/docker/scripts/smoke-test.sh`. Standalone Sync Server dev: `docker compose -f deploy/docker/compose.sync.yaml up -d --build` from the repo root.
