Single-entry Electron host (`main.cjs`) bootstraps the app, registers privileged custom schemes (`folia-cover`, `transcode://`, `folia-mod://`), then composes feature modules via dependency injection. Subsystems are isolated into sibling directories:
- `modSystem/` — third-party mod loader with manifest validation, digest/signature verification, per-mod error boundaries, a sandboxed `modApi`, file-grant store, and an IPC + `folia-mod://` protocol serving renderer-side client code.
- `transcode/` — FFmpeg-backed audio transcoding service with its own cache, protocol handler, runner, and a single-threaded job queue; reuses `modSystem/ffmpeg.cjs` for binary resolution.
- `analysis/` — thin main-process host that forks a separate Electron `utilityProcess` worker (`worker.cjs`) running Python sidecar (`htdemucs_runner.py`) and onnxruntime models, with idle timeout, per-request deadlines, and GPU-abort pinning.
- Top-level files each implement one concern: wallpaper controllers per OS (`macWallpaperController.cjs`, `windowsWallpaperController.cjs`, `wallpaperWatchdog.cjs`, `windowPlaybackHandoff.cjs`), API bridges for KuGou/QQ/Netease, Discord presence, lyric proxy, AI text completion, Linux password-store selection, local cover assets, update channels, voice-input pause, display sleep blocking, and stage (OBS) integration.

Dependency direction is strictly renderer → preload (`contextBridge.exposeInMainWorld('electron', ...)`) → `ipcRenderer.invoke`/`send` → `main.cjs` handlers → feature module factories. Cross-subsystem coupling goes through explicit constructor options (e.g. `createTranscodeService({app,protocol,net,...})`, `createAnalysisHost({app,ipcMain,getModelsDirs,...})`) so modules can be unit-tested headless. Platform-specific behavior is gated by `process.platform` checks rather than separate binaries, with native helpers (`windowtolayer`, `folia-wallpaper-helper.exe`) spawned only when present.
