- Feature modules expose a factory function (e.g. `createTranscodeService`, `createAnalysisHost`, `createModSystem`, `createKugouApiBridge`) that accepts a dependency-injection object of `app`, `protocol`, `store`, `spawnFn`, etc., instead of importing Electron globals directly.
- Renderer-facing capabilities are published through `preload.cjs` as methods on a single `window.electron` namespace, pairing each `ipcRenderer.invoke` request with a matching `ipcRenderer.on` subscription method whose name mirrors the event string.
- IPC channel names are declared as constants grouped in an `IPC` object (or exported constants like `TRANSCODE_PROTOCOL_SCHEME`) and referenced uniformly by both the renderer bridge and the main-process handler, avoiding magic strings.
- Platform-specific behavior is implemented as separate modules (`macWallpaperController.cjs`, `windowsWallpaperController.cjs`, `linuxPasswordStore.cjs`) selected at runtime via `process.platform` guards rather than conditional branches inside shared code.
- Long-running background work is isolated in child processes (`utilityProcess.fork` for analysis, `child_process.spawn` for FFmpeg/windowtolayer/helper) so failures cannot freeze the renderer thread and memory is reclaimed on process exit.
- User-visible dialog text is mirrored in-process in multiple locales (see `TRUST_DIALOG_LOCALE` in `modSystem/modSystem.cjs`) because the main process cannot access the renderer's i18n bundle.
