Three parallel entry points are exposed via npm scripts: `npm run dev:cf` (Wrangler dev), `npm run deploy:cf` (Wrangler deploy), and `npm run dev:node` / `npm run start:node` / `npm run build:node` (Node + SQLite). Interactive setup is provided by `install.sh` (Linux/macOS/WSL) and `install.ps1` (PowerShell), which create the D1 database, generate `wrangler.local.toml`, inject `SYNC_TOKEN`/`DASHBOARD_TOKEN` secrets, and deploy. For Docker, the service is built from the repo root via `docker compose -f deploy/docker/compose.sync.yaml up -d --build` and listens on container port 3000 mapped to host 13000.
