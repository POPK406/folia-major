Each subdirectory under `mods/` is an independent Folium 1 mod following a fixed layout: a `mod.json` manifest declares id/version/client/main/permissions/experimental, a `client.mjs` ESM entry exports `activate(folium)` that registers against host registries (visualizers, tunings, stageLayers, controlButtons, progressLayers, styles, commands, settingsSections), and an optional `index.cjs` main entry for Node-side work. Signed mods carry a `folium.sig.json` (Ed25519) alongside a `preview.jpg`. The samples cover the full spectrum of stable APIs — pure client UI extensions (`k3panel`, `more-progress-buttons`, `sample-progress-bar`, `sample-aurora-visualizer`, `sample-rickroll`) and a mixed client+main example (`sample-transparent-mov-export` using `folium.rpc` to delegate ffmpeg export). `visualizer52hz` is the most complex, bundling its own PixiJS vendor tree and multiple helper modules (`beatDetector`, `distanceField`, `lineLayout`, `lyricText`, `pithShape`, `ponder`, `rippleFilter`, `stage.mjs`) to demonstrate advanced visualizer + ponder targets + audio analysis. Dependency direction is strictly one-way: mods import only relative paths inside their own directory; no bare npm specifiers are allowed by the loader.
