Flat collection of Markdown guides with a small subdirectory convention: `chore/` holds maintenance notes (known non-bug issues, legacy deprecations), `desktop/` holds per-OS troubleshooting (e.g. macOS app-damaged), and `folium/` documents the Folium plugin system (`api.md`, `contributing.md`). Top-level files cover cross-cutting topics — `technical.md` is the central dev/deploy hub, `CODEMAP.md` is auto-generated by `npm run codemap` from the TypeScript compiler/module graph and consumed by CI to detect structural drift, while other files are standalone guides (lyric API, local library management, automix memory optimization, QQ Music deployment, wallpaper mode, etc.). There is no build step or runtime code in this module; it is purely source-of-truth documentation consumed by contributors and the external docs site at folia-site.cielaniska.top.
