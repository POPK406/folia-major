The suite is split into four parallel runtimes under `test/`:
- `component/*.spec.ts` — Playwright component tests that mount individual React components via a custom `mount` fixture from `fixtures.ts`, which seeds deterministic `localStorage` state before page load.
- `ui/*.spec.ts` — Playwright browser-level tests using shared helpers in `helpers/appFixtures.ts` (`installBaseState`, `mockNeteaseApi`, `mockNavidromeApi`, `openApp`) to bootstrap a fully mocked Netease / Navidrome / local-library world; visual baselines live as PNG snapshots under `ui/app.screenshot.spec.ts-snapshots/`.
- `unit/**/*.test.ts` — Vitest unit tests mirroring the `src/` module tree one-to-one (e.g. `lyrics/`, `onlineMusic/`, `visualizer/lumiere/`, `mod-system/`, `stores/`, `lattice/`), with per-directory fixtures and snapshot contracts.
- `manual/` — One-off diagnostic scripts (Python, Node, PowerShell) not part of CI.

Cross-cutting setup lives in `helpers/appState.ts`, which reads `package.json` version at runtime so the guide-onboarding key never drifts across releases, and exposes `waitForAppMounted` waiting on the `#app-splash` sentinel. The `ui/helpers/appFixtures.ts` centralizes all browser-side mocking: it injects init scripts via `page.addInitScript`, overrides `window.electron`, `Worker`, `Audio`, `showDirectoryPicker`, and `navigator.language`, and routes HTTP calls through `page.route`. Dependency direction is strictly inward: specs import fixtures/helpers but never the app source directly except for constants like `MOTION_SURFACE_IDS` used to freeze every motion surface deterministically.
