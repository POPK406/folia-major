Root scripts compose the full lifecycle: `npm run dev` starts the Vite SPA; `npm run dev:electron` concurrently boots Vite and Electron with helper binaries resolved from `build/windowtolayer` and `build/folia-wallpaper-helper.exe`; `npm run build:electron` triggers Vite build plus native helper builds before invoking `electron-builder`; `npm run test` runs Vitest, `npm run test:ui` runs Playwright; `npm run build:vercel-api` compiles the Vercel API sources under `api-ts/` separately from the frontend.
