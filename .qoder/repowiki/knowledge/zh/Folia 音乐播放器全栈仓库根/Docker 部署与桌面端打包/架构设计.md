模块分为两个独立子域：
- `deploy/docker/`：以 `compose.yaml` 为发布入口，定义 gateway（Nginx + Vite 前端）、backend（Node API）、netease-api/kugou-api/qq-api（音乐平台代理）和 sync-server（独立 SQLite 同步服务）六个服务；通过三个桥接网络 `folia-edge` / `folia-internal` / `folia-sync` 实现对外暴露、内部互通与网络隔离，sync-server 单独挂在 `folia-sync` 网段且不与 Web 内部服务互通。`compose.build.yaml` 将镜像源切到本地 `images/*.Dockerfile` 多阶段构建，`compose.sync.yaml` 仅拉起 sync-server 供开发使用。每个服务的运行时由 `entrypoint.sh` 注入配置（如 gateway 用 `envsubst` 渲染 `nginx.conf.template`），并通过 `healthcheck` 探测 `/healthz`、`/api/healthz`、`/login/status`、`/health` 等端点。
- `packaging/`：面向 Electron 桌面端发行产物。`ffmpeg/fetch-ffmpeg.mjs` 从预编译 release 下载并校验 SHA256，产出 `build/ffmpeg/<os>-<arch>`；`linux/build-windowtolayer.mjs` 拉取固定上游 commit 并应用 `patches/` 下的补丁后 `cargo build --release`；`windows/build-wallpaper-helper.mjs` 在 Windows 上编译同目录 Rust crate 生成 `folia-wallpaper-helper.exe`；`aur/folia-major-bin/PKGBUILD` 把 GitHub Release 中的 Linux 二进制安装到 `/opt/folia-major` 并创建桌面入口。所有外部依赖均通过固定版本/commit/tag 锁定，避免 CI 环境差异。
