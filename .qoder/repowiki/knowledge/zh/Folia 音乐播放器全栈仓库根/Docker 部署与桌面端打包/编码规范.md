- Compose 服务统一设置 `read_only: true`、`security_opt: no-new-privileges:true`，并将可写目录挂载到 `tmpfs`，保持容器只读根文件系统。
- 每个服务在 Compose 中声明 `healthcheck`，通过内嵌的 `node -e "fetch(...)"` 或 `wget` 探测各自健康端点，并以 `condition: service_healthy` 作为 depends_on 条件。
- 环境变量统一走 `${VAR:-default}` 语法并提供 `.env.example` 模板，敏感值（SYNC_TOKEN、AI 密钥）不写入镜像，仅在运行时注入。
- Dockerfile 采用 builder/runner 双阶段构建，runner 阶段仅复制产物并 `USER node`，构建期依赖在 builder 阶段安装并在 runner 阶段删除。
- 外部二进制依赖（FFmpeg、windowtolayer、wallpaper-helper）通过 Node 脚本在构建时下载/编译并输出到 `build/`，脚本对上游来源进行固定 tag/commit 与 SHA256 校验。
- smoke-test.sh 同时断言公开端点可达性、HTML 骨架、AI provider 注入结果以及内部服务未意外暴露宿主机端口，确保网络隔离契约。
