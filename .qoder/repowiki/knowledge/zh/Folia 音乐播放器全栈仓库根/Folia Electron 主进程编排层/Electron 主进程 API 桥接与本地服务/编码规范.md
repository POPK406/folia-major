- 敏感凭据（Cookie、token、musickey）一律经 `safeStorage.encryptString` 以 base64 密文写入 electron-store，并以带 `version` 字段的 envelope 对象承载，便于未来迁移。
- 对外暴露的工厂函数（如 `createKugouApiBridge`、`createStageApi`、`createLyricApi`、`createQqAuthSessionRepository`、`createNeteaseLoginDiagnostics`）统一接收配置对象，将 store/safeStorage/logger 等依赖作为参数注入以便测试。
- HTTP 响应统一设置 `Access-Control-Allow-Origin: *` 与标准 CORS 头，跨域请求通过 Authorization Bearer 或 URL query `token` 校验。
- 网络调用普遍包裹超时与重试：`withTimeout` 配合指数退避+抖动（`retryStartupOperation`），AI 请求则用 `AbortSignal.timeout` 并在失败时包装为带 label 的 Error。
- 日志与诊断输出固定以 `[模块名]` 前缀（如 `[KuGouSession]`、`[Netease API]`、`[Stage]`、`[ai]`、`[QQ API]`）区分来源。
- 对 Electron 平台差异（尤其是 Linux `basic_text` 后端）采用显式检测并抛出明确错误，而非静默降级到明文存储。
