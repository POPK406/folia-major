模块按平台与职责切分为若干独立 CJS 文件，每个文件暴露一个 `createXxxController` 工厂函数，由上层 main.cjs 注入依赖（store、spawn、screen、logWarn 等），使状态机可无 Electron 运行头单元测试。

- macOS 路径：`macWallpaperController.cjs` 通过 `koffi` 直接调用 CoreGraphics/NSWindow/Finder 层常量，把 BrowserWindow sink 到 Finder 图标层之下；同时用 CGEventTap 监听桌面点击并转发到渲染进程，还负责 Dock auto-hide 的 defaults 读写与 crash-marker 恢复，所有 FFI 入口 fail-soft，不可用时 `isAvailable()` 返回 false。
- Windows 路径：`windowsWallpaperController.cjs` 管理 `folia-wallpaper-helper.exe` 子进程，通过 JSONL stdout 心跳协议维持 attach/detach，内置崩溃循环断路器（persisted failure count + healthy uptime）；`windowsWallpaperMouse.cjs` 将 helper 的物理像素鼠标事件经 `screen.screenToDipPoint` 转 DIP 后通过 `webContents.sendInputEvent` 注入 Chromium；`windowsWallpaperTarget.cjs` 按优先级（当前普通窗口 > 会话目标 > WINDOW_BOUNDS > 主显示器）解析壁纸所在显示器。
- Linux/Wayland/X11 路径：`wallpaperWatchdog.cjs` 作为 jumpboard 守护 `windowtolayer` 子进程，检测父进程存活并在 wtl 死亡时 relaunch 为普通窗口，同时统计 wrapped 崩溃次数以禁用壁纸模式。
- 通用辅助：`displaySleepBlocker.cjs` 封装 `powerSaveBlocker` 生命周期，`discordPresence.cjs` 基于 `@xhayper/discord-rpc` 维护 Rich Presence 活动。

依赖方向单向：这些模块被 main.cjs 消费，彼此之间除 Windows 三件套（controller → mouse/target）外无相互引用；所有副作用（child_process、fs、Electron API、koffi）均通过 options 注入或 platform-gated require，保证纯逻辑可测。
