- API 请求体统一通过 `c.req.json<T>().catch(() => null)` 解析并以 `isRecord` / `typeof` 守卫校验后再落库。
- 所有写操作使用 `ON CONFLICT ... DO UPDATE SET ... WHERE excluded.updated_at >= ...` 实现基于时间戳的幂等覆盖。
- 主题按 `hashSyncString(fingerprint) % THEME_BUCKET_COUNT` 计算 `bucket_id`，并通过 XOR 累计 hashDelta 维护 `theme_buckets` 摘要。
- 批量写入统一走 `db.batch([...])` 聚合多条 `prepare(...).bind(...).run()` 语句，并在 Node 端由 `D1Emulator` 用 `db.transaction` 包裹保证原子性。
- 环境变量（`SYNC_TOKEN`、`DASHBOARD_TOKEN`、`FOLIA_SYNC_DB`）通过 Hono 的 `<{ Bindings: Env }>` 类型约束，运行时由 cloudflare/node 两端的适配器分别注入。
