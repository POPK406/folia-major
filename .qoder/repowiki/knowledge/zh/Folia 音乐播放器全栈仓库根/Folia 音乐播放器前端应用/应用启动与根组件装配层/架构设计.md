模块按三层组织启动链路：
- 运行时注入层 `src/index.tsx`：在 React 渲染前安装 Node `Buffer` polyfill、console log capture、debug module、memory sample feed 和帧率限制器，再通过 `void import('./bootstrap')` 动态加载主引导逻辑。
- 多入口挂载层 `src/bootstrap.tsx`：通过 `isMainAppSurface / isObsBrowserSourceSurface / isRemoteControlSurface` 等 URL 探测函数，在同一个 `<AppSplashGate>` 下选择挂载 `App`、`ObsBrowserSourceApp`、`ObsNowPlayingSourceApp`、`ObsPlayerCapSourceApp` 或 `RemoteControlApp`；仅在 main app 时异步执行 Folium mod 初始化（command palette sync、host events、client loader、saved selections），最后等待 `initializeLocalCoverRuntime` 完成后再 `root.render`。
- 顶层编排层 `src/App.tsx`：聚合所有领域 store（Zustand）、hooks（播放桥接、主题、导航、会话恢复、外部 surface 等）与子组件（AppShell/Home/VisualizerRenderer/AppOverlays/PlayerPanel/AppDialogs/CommandPalette 等），是业务装配中心而非展示组件。
- 全局契约层 `src/types.ts` + `src/vite-env.d.ts`：前者导出 LyricData/Theme/各 visualizer tuning 等运行时共享类型，后者扩展 `Window.electron` 暴露 Electron IPC 能力（音频缓存、自动混音模型、OBS/Stage/Lyric API、远程遥控、调试日志等）并声明 Vite 注入的 `__COMMIT_HASH__` 等常量。
依赖方向单向向下：index → bootstrap → App → components/stores/services/utils，types 被全仓引用但不反向依赖业务。
