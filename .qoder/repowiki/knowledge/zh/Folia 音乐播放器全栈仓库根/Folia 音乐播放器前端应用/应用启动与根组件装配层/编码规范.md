- 多运行环境（main app / OBS browser source / remote control / now-playing / playercap）通过 `isMainAppSurface`、`isObsBrowserSourceSurface`、`isRemoteControlSurface` 等布尔标志在 bootstrap 层做分支挂载，而不是用路由切换。
- Zustand store 订阅采用 `useStore(useShallow(state => ({ ... })))` 或 `selectXxxSettingsSnapshot` 快照选择器模式，避免整棵 store 变更触发重渲染。
- Electron 能力统一以 `window.electron.*` 命名空间暴露，并在 `vite-env.d.ts` 中集中声明方法签名与回调类型，浏览器构建下这些属性缺失时调用方需做可选链或空值判断。
- 重型或仅开发可见的功能（如 `AutomixTransitionAnimation`、`Lattice`、`coverSizeAudit`）使用 `lazy(() => import(...))` 或条件 `import.meta.env.DEV` 包裹，避免污染 bootstrap chunk。
- 全局副作用（i18n 配置、CSS、motion settings store 写入 `<html data-reduce-motion>`）放在 bootstrap 的静态 import 中，确保在 React 渲染之前同步生效。
