- 组件统一以 `React.FC<Props>` 形式导出，并通过解构 props 接收参数，类型定义与组件放在同一文件顶部。
- UI 文案一律通过 `useTranslation()` 的 `t(key)` 获取，禁止硬编码字符串。
- 视觉主题色通过 CSS 自定义属性（如 `--text-primary`、`--folium-progress-fill`）传入，组件内部用 Tailwind 半透明类（`bg-black/40`、`backdrop-blur-*`）实现玻璃态风格。
- 进入/退出动画统一使用 framer-motion 的 `<motion.div>` 配合 `AnimatePresence`，并以 `initial/animate/exit` 描述状态切换。
- Electron 相关逻辑通过 `window.electron` 访问并做存在性检查（如 `if (!electron) return null`），避免在非 Electron 环境报错。
- Folium 扩展点通过 `data-folium-part="..."` 标记 DOM 节点，供 mod CSS 在 `@layer folium-mods` 中覆盖样式，组件自身不内联颜色。
