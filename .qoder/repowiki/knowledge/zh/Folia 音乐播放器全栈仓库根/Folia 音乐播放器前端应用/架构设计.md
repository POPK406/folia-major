以 src/index.tsx → bootstrap.tsx → App.tsx 为启动主轴：bootstrap.tsx 根据 Electron/浏览器/OBS 等宿主环境选择挂载点并注入 i18n、主题、Electron IPC 桥；App.tsx 作为顶层编排容器，组合 app_shell（AppShell/Home/PlayerPanel）、command-palette、visualizer、ponder、mods、panelTab、modal 等子模块。
- 跨子模块共享状态集中在 stores/（usePlaybackStore、useThemeSettingsStore、useGridSurfaceStore 等）与 hooks/（useElectronPlaybackBridge、usePlaybackTransportController 等），UI 组件通过 hooks 订阅而非直接 import store。
- 能力扩展点：mods/ 提供 ModSurfaceRenderer 与 Folium 宿主桥，允许外部 mod 在命令面板、设置页、Ponder 目标中注册自定义 surface/target；visualizer/ 通过 registry.tsx + definition.ts 暴露可插拔的可视化模式；ponder/ 通过 ponderRegistry.ts 注册页面引导 target。
- 类型契约集中在 types/（appPlayback、onlineMusic、ponder、visualizerModes 等），被 services/、components/、hooks/ 共同消费，形成单向依赖：components → hooks/stores → services/types。
- 计算密集型逻辑下沉到 workers/（automixAnalysis、lyricsParser、metadataParser），由 services/automix 与 utils/lyrics 通过 postMessage 调用。
