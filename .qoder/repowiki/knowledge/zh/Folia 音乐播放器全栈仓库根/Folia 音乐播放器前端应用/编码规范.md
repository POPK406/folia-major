- 组件与其模型解耦：每个复杂 UI 子目录采用 buildXxxModel.ts + useXxxModel.ts + XxxView.tsx 三件套分离数据与渲染。
- 全局状态统一通过 stores/*.ts 暴露的 Zustand store，并由 hooks/ 中的 useXxxStore 封装订阅逻辑，组件不直接 import store。
- 可插拔能力（可视化模式、Ponder target、Mod surface、在线音乐 provider）均通过各自的 registry.ts / registry.tsx 集中注册，组件侧只消费已注册的实例。
- 重型同步或解析逻辑放入 workers/*.worker.ts，由 services/ 层通过 postMessage 调度，避免阻塞主线程。
- 国际化文案统一经 i18n/config.ts 加载，组件使用 t('...') 访问 locales 下的 en/in/zh-CN 文件。
