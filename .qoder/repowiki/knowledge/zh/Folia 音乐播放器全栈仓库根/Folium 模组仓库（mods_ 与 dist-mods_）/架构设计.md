本模块是纯数据 + 可执行代码的模组集合，不含加载逻辑；实际加载由宿主 `electron/modSystem` 完成。

- 目录结构：每个模组一个子目录，遵循 `mod.json` + 可选 `client.mjs`（渲染端 ESM）+ 可选 `index.cjs`（主进程 Node）+ `preview.jpg` + `folium.sig.json` 的约定，详见 `mods/README.md`。
- `mods/`：开发态示例模组（k3panel、more-progress-buttons、sample-*、visualizer52hz），全部用官方 Ed25519 密钥签名，随仓库一起分发并由测试校验。
- `dist-mods/`：从宿主内置功能提取的可安装模组（tide-background、tidex），以及预打包的 `tide-background-1.0.0.zip`，供 UI 拖放安装。
- 依赖方向单向：模组通过 `folium.registries.*` / `folium.events.on` / `folium.playback` / `folium.ui` / `folium.net.fetch` / `folium.storage` 等契约 API 接入宿主，不直接 import 宿主内部；第三方库以相对路径放入 `vendor/`（如 visualizer52hz、tide-background/vendor）。
- 安全边界：`folium.sig.json` 使用 Ed25519 对模组内容做 sha256 摘要签名，由宿主内置公钥校验；`permissions` 字段仅作为 fail-closed 的功能开关，不构成沙箱隔离。
- 版本策略：`mod.json` 中 `folium: 1` 表示 Folium 1 契约，`folia` 字段钉死宿主版本范围（使用 `internals` 时必填）。
