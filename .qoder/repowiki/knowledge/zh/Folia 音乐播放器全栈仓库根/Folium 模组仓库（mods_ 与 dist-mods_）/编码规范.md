- 每个模组目录提供 `mod.json` 清单，声明 `folium: 1`、`id`、`version`、`client`/`main` 入口及可选 `permissions`、`embedOrigins`、`experimental`、`folia` 字段。
- client 入口统一导出默认函数 `activate(folium)`，通过 `folium.registries.*.register()` 注册 visualizer/background/tunings/stageLayers 等条目，返回 dispose 函数用于清理。
- 设置参数使用统一的 `FoliumParam` schema（key/type/label/min/max/step/defaultValue/group），label 与 description 采用 `{ 'zh-CN': ..., en: ... }` 双语对象。
- 所有文字标签（label/description/组名）同时提供 `'zh-CN'` 与 `en` 键，保持界面语言切换可用。
- 需要宿主内部能力或跨进程能力的模组在 `mod.json` 中显式声明 `permissions`（如 `net.fetch`、`ui.stage`、`filesystem.data`），未声明的调用 fail closed。
- 官方示例模组附带 `folium.sig.json`，包含 format/version/modId/modVersion/digest/keyId/signedAt/signature 字段，由宿主内置公钥校验。
