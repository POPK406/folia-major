模块按部署目标分为三层：
- `api/` 与 `api-ts/`：Vercel Edge Runtime 入口，`tsconfig.json` 将 `api-ts/*.ts` 编译输出到 `api/`，每个文件对应一个扁平路由（`generate-theme`、`lyric-proxy`、`segment-lyrics`、`qq`），其中 `qq.js`/`qq.ts` 通过 `vercel.json` rewrite 把 `/api/qq?path=...` 还原为后端路径。
- `worker/`：Cloudflare Workers 单入口 `index.ts`，在 `fetch` 中按 pathname 分发到各 handler；额外导出 `QqQrChannel` Durable Object，用 MQTT WebSocket 维持扫码登录的跨调用状态，并通过 `alarm` 做 TTL 兜底释放。
- 依赖方向单向：`worker/*` 与 `api-ts/*` 共享业务逻辑（Gemini/OpenAI 主题生成、歌词分段、QQ 服务端less 封装），`api/*.js` 仅作为 Vercel 的 Edge shim 转发请求。
- 外部依赖集中在 `@yakult-green-tea/qq-music-api`（QQ 登录 + MQTT）与 `@google/genai`（Gemini），并通过 `../shared/themeSanitizer.mjs` 对 AI 返回的双主题做清洗。
