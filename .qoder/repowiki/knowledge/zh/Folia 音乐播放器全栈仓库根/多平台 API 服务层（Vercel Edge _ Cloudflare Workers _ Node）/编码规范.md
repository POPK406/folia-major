- 每个 handler 暴露为独立的 `handleXxx(request, env)` 函数，由 `index.ts` 或 Vercel 路由统一按 pathname 分发，避免在入口内写业务逻辑。
- 对外响应统一通过 `Response.json` 或自定义 `json(body, status)` 辅助函数构造，并固定 `content-type: application/json; charset=utf-8`。
- 环境变量从 `env` 参数读取（如 `GEMINI_API_KEY`、`OPENAI_API_*`、`QQ_SESSION_SECRET`），不在模块顶层访问 `process.env`，便于 Worker 与 Edge 共用同一实现。
- QQ 相关代码通过 `@yakult-green-tea/qq-music-api/serverless` 接入，并在注释中强调 Edge Runtime 零 `node:*` 约束作为守门人。
- Durable Object 的生命周期通过 `open`/`poll`/`close`/`alarm` 四件套管理 MQTT 连接，并以 `MAX_TTL_MS` 截断 TTL 防止计费失控。
