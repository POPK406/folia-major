- 组件与 UI 测试通过 `page.addInitScript` 在页面脚本执行前写入 `localStorage` 种子（`i18nextLng`、`static_mode`、引导版本 key），而非在 `window.mount` 之后设置，以匹配 store 模块加载时的读取时机。
- UI 测试统一通过 `installBaseState` + `mockNeteaseApi` / `mockNavidromeApi` 组合注入 mock 数据与网络拦截，避免在每个 spec 中重复编写 mock 逻辑。
- 单元测试按 `src/` 源码目录镜像组织子目录（如 `lyrics/`、`lattice/`、`visualizer/`、`services/`、`stores/`），每个被测模块对应一个 `.test.ts` 文件。
- 版本号与引导标识不硬编码，而是从 `package.json` 读取 `APP_VERSION` 并通过 `GUIDE_VERSION_STORAGE_KEY` 常量引用，防止发版后引导弹窗干扰测试。
- 截图类测试通过 `emulateMedia({ reducedMotion: 'reduce' })` 并在样式表中隐藏所有 `canvas`，消除视觉化渲染差异导致的快照抖动。
