- 探针通过默认导出 `ProbeDefinition` 对象并在 `registry.ts` 中由 `import.meta.glob` 自动发现，新增探针只需新建 `*.probe.tsx` 文件，无需修改注册表。
- MCP 工具以单文件形式放在 `tools/` 下，每个文件对应一个 MCP tool schema，统一通过 `cli.mjs` 分发调用。
- Vite 插件使用虚拟模块模式（`\0` 前缀 ID），在 `configureServer` 中手动 `server.watcher.add` 被扫描路径并调用 `invalidateModule` + `full-reload` 实现 HMR。
- 构建期脚本优先复用仓库已安装的包（tsgo、Vite parseAst）而非引入新依赖，以保持零新增依赖。
