模块按用途分为三个并列子目录，彼此无代码依赖：
- `docs/`：纯 Markdown 技术文档，按主题分目录（`chore/` 记录已知非 Bug 与废弃说明、`desktop/macos-app-damaged.md` 桌面端问题、`folium/` 插件 API 与贡献指南），根目录下为架构与设计类文档（如 `CODEMAP.md`、`technical.md`、`local-library-management.md`、`lyric-api.md` 等）。
- `public/`：构建产物之外的静态资源，包含 `runtime-config.js`（空壳，供 Vite 环境变量注入 `window.__FOLIA_RUNTIME_CONFIG__`）、`icon.svg` 图标，以及 `folia-cover-sw.js`——一个独立的 Service Worker，拦截 `/__folia_cover/sha256:<digest>` 请求，从 OPFS 的 `folia-cache/local-cover-assets` 读取内容寻址封面文件并可选生成缩略图。
- `.github/`：GitHub 生态资产，`ISSUE_TEMPLATE/` 提供「报告问题」和「功能建议」两个中文模板；`workflows/` 下是完整的 CI 流水线（canary/nightly/release-candidate 预发布、Docker 镜像构建推送、Electron 桌面版发布、PR 单元测试、`codemap-sync.yml` 在 main 分支自动重生成 `docs/CODEMAP.md` 并提交）。

依赖方向单向向外：本模块不引入任何业务源码，仅被仓库根脚本（如 `npm run codemap`）或 GitHub Actions 引用。
