- CI 工作流使用 YAML 描述，并通过 `concurrency.group` + `cancel-in-progress: false` 串行化对同一分支的写操作，防止并发 checkout 冲突。
- Issue 模板统一采用 YAML front matter 声明 `name`/`about`/`title`/`labels`，正文使用中文引导字段（Bug 描述、重现步骤、报错信息、预期行为、设备环境）。
- 公共 JS 资源以注释首行标注来源路径（如 `// public/folia-cover-sw.js`），并在文件顶部集中声明常量（路径前缀、正则、允许的 MIME 类型等）。
