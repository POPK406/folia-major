根 `package.json` 是跨子模块的唯一编排点：`dev`/`build` 通过 Vite 同时构建 `frontend_app`（React）与 `electron_app`（主进程），并在 `build` 前调用 `tsc -p api-ts/tsconfig.json` 预编译 `api_services`；`sync_server` 独立于该流水线但复用同一份 `shared_runtime` 工具集。

- 运行时代划分：`frontend_app` 跑在浏览器/Electron 渲染进程；`electron_app` 作为主进程桥接原生能力并通过 IPC 暴露给渲染层；`api_services` 与 `sync_server` 提供 Edge/Cloudflare/Node 后端能力；`shared_runtime` 被 Electron 主进程与浏览器端共同消费。
- 数据与协议边界：Electron 主进程通过自定义协议与 IPC 向渲染进程暴露壁纸、转码、分析等能力；API 服务对外暴露主题生成、歌词代理与 QQ 登录 REST 接口；同步服务通过 Bearer Token 鉴权供客户端拉取外观设置与 AI 主题库。
- 扩展点：`mods_catalog` 下的 Folium v1.x 模组由 `electron_app` 中的模组加载器扫描并激活，仅桌面端可用。
- 部署面：Vercel/Cloudflare Workers/Node 三种后端形态 + Docker Compose 全栈 + electron-builder 打包 Windows/macOS/Linux 桌面安装包，统一由根脚本驱动。
