- 对外暴露的错误统一携带 HTTP status 码（如 `SegmentationRequestError(message, 502)`），以便上层适配器直接映射响应状态。
- LLM 请求参数采用“能力探测 + 缓存”模式：首次失败后记录 endpoint+model 的能力位（如 `responseFormat=false`、`tokenField='max_completion_tokens'`），后续请求自动裁剪不支持的字段。
- 对不可信模型输出采用“结构校验 + 逐行宽容”策略：结构性错误抛异常，单行内容不一致则返回 `null` 并计入 `rejections`，不阻断整批处理。
- 主题与配置字段通过独立的 `normalizeXxx(value, fallback)` 函数进行白名单校验，缺失或非法值回退到传入的 fallback 对象。
- 面向不同运行时的代码保持 ESM 与 CommonJS 双份实现（`.mjs` / `.cjs`），并通过单元测试确保行为一致。
