### Folia
- 定义：本项目产品名，一个以全屏沉浸式歌词可视化为核心的在线音乐播放器，提供 Electron 桌面端与 Web 端两种形态。
- 别名：folia-major

### Folium
- 定义：Folia 的模组平台（v1.x），允许在桌面端加载歌词动画、背景、播放页图层、命令等扩展，模组需签名认证并在原生窗口中确认。
- 别名：模组系统、mod system

### visualizer
- 定义：Folia 的「播放页」即全屏歌词可视化模块，包含 7 种背景层与 14 种内建歌词动画模式，是项目的核心界面。
- 别名：播放页、歌词可视化

### Tide
- 定义：Folia 的一个背景类型（tide-background），属于播放页背景层之一，当前正在 `feat/tide-background` 分支下开发。
- 别名：tide-background

### Sync Server
- 定义：Folia 提供的可选官方同步服务端，用于在多设备之间同步外观设置与 AI 主题库，支持 Cloudflare Workers/D1、Docker 与 SQLite 三种部署方式。
- 别名：同步服务端、sync-server

### Stage API
- 定义：Folia 暴露给外部程序与播放器深度集成的 API，可通过 `npm run stage:client` 启动本地联调台进行调试。
- 别名：stage-client

### Now Playing
- 定义：接入外部播放器（如 macOS 系统媒体控件）的能力，通过 now-playing-service 获取歌曲、时间轴与歌词信息并驱动 Folia 舞台视图与全屏歌词渲染。
- 别名：now-playing-service

### Realeco
- 定义：Folia 桌面端的正式发行通道，仅在 main 修改根目录 `realeco-release` 时触发，发布到 GitHub Releases latest 标签。
- 别名：正式版

### Limo
- 定义：Folia 桌面端的 Nightly 预发布通道，对应 beta 更新来源。
- 别名：夜版

### Cielo
- 定义：Folia 桌面端的 Canary 预发布通道，对应 alpha 更新来源，可创建独立的 `cielo-<branch>-<sha>` prerelease。
- 别名：金丝雀

### 模组市场
- 定义：Folium 模组的分发平台（folium-compound.vercel.app），提供官方与经过审查的社区模组，安装后带 Folium 签名标记「官方认证」。
- 别名：folium-compound

### 本地音乐库
- 定义：Folia 导入本地音频文件后建立索引（不上传文件内容），并可自动匹配在线歌词与封面，支持 LDDC 增强型逐字歌词格式。
- 别名：本地库、local library

### 壁纸模式
- 定义：Folia 的桌面端特性，可将播放画面作为系统壁纸渲染，涉及 Windows/macOS/Linux 各平台的控制器实现。
- 别名：wallpaper mode
