## 简介
Folia Major 是一个以全屏沉浸式歌词播放为核心的音乐应用，支持本地音乐库、网易云、酷狗、QQ 音乐等在线服务，并提供桌面端与 Web 端两种运行形态。新用户可以在最短时间内完成安装、添加本地音乐、连接在线服务并体验全屏歌词效果。

## 环境要求
- **Node.js 版本**：项目声明需要 Node.js `>=24`。
- **Docker 部署**：如果使用 Docker Compose 全栈部署，需要 Docker Engine 24+ 与 Docker Compose v2。
- **浏览器能力（Web 版）**：推荐使用支持 File System Access API 的 Chromium 系浏览器；HTTPS 安全上下文对本地文件夹导入、PWA、音频设备枚举等功能很重要。

## 安装方式
Folia 提供多种获取和运行方式，适合不同技术背景的用户。

### 直接下载安装包
适合希望“即装即用”的桌面用户：
- Windows、macOS、Linux：前往 Releases 页面下载最新安装包。
- Arch Linux：可通过 AUR 获取 `folia-major-bin`。
- Flatpak：社区提供的第三方 Flatpak。

国内网络从 GitHub Releases 下载较慢时，可使用文档中提供的网盘链接作为替代。

### 从源码构建
适合开发者或需要自定义构建的用户：
- 仓库根目录包含 Vite、TypeScript、Electron 构建脚本。
- 开发模式使用 `vite dev`。
- 桌面端打包涉及 Electron Builder、FFmpeg 辅助工具、窗口层级工具和壁纸助手等构建步骤。
- 如果只需要 Web 前端，可参考仓库中的 Vite 相关脚本；如果需要桌面端，则需要满足 Node.js >=24 以及 Electron 构建依赖。

### Docker 容器化部署
适合希望在 NAS、服务器或容器中运行 Folia Web 全栈的用户：
- 官方提供 `compose.yaml`，包含 Web 网关、后端、网易云接口、酷狗接口、QQ 音乐接口和独立 Sync Server。
- 对外只暴露 Web 网关和 Sync Server 端口，其余服务通过 Docker 内部网络访问。
- 默认 Web 地址为 `http://NAS-IP:18080`，Sync Server 健康检查地址为 `http://NAS-IP:13000/health`。

## 基础配置
### 环境变量与关键配置项
| 配置项 | 说明 | 注意事项 |
| --- | --- | --- |
| `VITE_QQ_API_BASE` | Web 前端使用的 QQ 音乐 API 基础路径 | 自托管 gateway 通常不需要额外设置；Serverless 部署常填 `/api/qq` |
| `QQ_SESSION_SECRET` | QQ 登录态加密密钥 | 服务端密钥，**不加 `VITE_` 前缀**；至少 32 字节随机值 |
| `SYNC_TOKEN` | Sync Server 客户端 Bearer Token | 至少八位，必填；用于跨设备同步外观设置与 AI 主题 |
| `FOLIA_IMAGE_NAMESPACE` | Docker 镜像命名空间 | 模板默认使用官方镜像命名空间 |
| `FOLIA_STACK_VERSION` / `FOLIA_SYNC_VERSION` | 指定 Web 堆栈与 Sync Server 版本 | 不填写时使用 `latest` |
| `FOLIA_HTTP_BIND` / `FOLIA_HTTP_PORT` | Web 网关监听地址与端口 | 默认 `0.0.0.0:18080` |
| `FOLIA_SYNC_BIND` / `FOLIA_SYNC_PORT` | Sync Server 监听地址与端口 | 默认 `0.0.0.0:13000` |

### HTTPS 与安全上下文
- 普通 HTTP 可以在线搜索、播放、歌词和部分可视化，但局域网 IP 上的 HTTP 不属于浏览器安全上下文。
- 启用 HTTPS 后，本地音乐目录导入、PWA、OPFS、音频设备枚举、标准剪贴板等能力更可靠。
- 推荐让反向代理终止 HTTPS，并将 HTTP 请求重定向到 HTTPS。
- 证书必须是浏览器信任的合法证书链；不支持将应用挂载在 `/folia/` 子路径。

## 桌面版完整流程
### 适用人群
- 希望直接安装即可使用。
- 需要更好的系统级能力，例如稳定的音频输出、窗口层级、壁纸辅助工具、模组系统等。
- 对浏览器安全上下文限制较敏感的用户。

### 安装步骤
1. 确认系统为 Windows、macOS 或 Linux。
2. 前往 Releases 页面下载对应平台的安装包。
3. 安装并启动 Folia 桌面端。
4. 首次打开后进入首页，找到本地音乐区域。
5. 选择“导入文件夹”，授权访问本地音乐目录。
6. 等待扫描完成，随后可以播放本地歌曲并体验全屏歌词。

### 桌面版优势
- 内置前后端运行环境，减少部署复杂度。
- 更适合本地音乐库管理、封面缓存、音频设备和系统集成。
- 支持实验性 Folium 模组系统（需在设置中开启）。

## Web 版完整流程
### 适用人群
- 希望快速上线或在浏览器中使用。
- 希望通过 Vercel、Cloudflare 或 Docker 部署。
- 希望移动端通过 PWA 或 Capacitor 打包使用。

### 方式一：Vercel 一键部署
1. 点击仓库 README 中的 Vercel 部署按钮。
2. 按 Vercel 提示创建项目。
3. 如需使用 QQ 音乐，设置环境变量：
   - `VITE_QQ_API_BASE` 填 `/api/qq`
   - `QQ_SESSION_SECRET` 填服务端密钥（不加 `VITE_` 前缀）
4. 部署完成后访问 Vercel 分配域名。

### 方式二：Cloudflare 部署
1. 使用 Cloudflare 一键部署按钮克隆仓库。
2. 配置 `QQ_SESSION_SECRET` 为 Worker secret。
3. 前端 `VITE_QQ_API_BASE` 填 `/api/qq`。
4. 可选：绑定 Durable Object 以启用 QQ 扫码登录通道。
5. 部署完成后访问 Cloudflare Workers 分配的域名。

### 方式三：Docker 容器化部署
1. 准备一个空目录。
2. 下载 `compose.yaml` 和 `.env.example`。
3. 生成 `SYNC_TOKEN` 并写入 `.env`。
4. 执行 `docker compose config`、`docker compose pull`、`docker compose up -d --wait`。
5. 访问默认 Web 地址 `http://NAS-IP:18080`。
6. 如需启用 HTTPS，请通过反向代理终止 TLS 并传递正确的转发头。

## 基本使用流程
### 第一步：添加本地音乐库
1. 打开 Folia 首页。
2. 进入本地音乐区域。
3. 选择“导入文件夹”。
4. 选择本地音乐目录并等待扫描。
5. 扫描完成后，可在海报墙或集合视图浏览本地歌曲。

**章节来源**
- [docs/local-library-management.md:48-58](file://docs/local-library-management.md#L48-L58)

### 第二步：连接在线音乐服务
- 支持网易云、酷狗、QQ 音乐等在线服务。
- 在线服务可用于搜索歌曲、补全元数据、匹配歌词和封面。
- 自动匹配顺序通常为网易云、QQ 音乐、酷狗音乐。
- 若自动匹配不准确，可手动选择候选或恢复本地信息。

## 常见问题与故障排除
### 无法导入本地文件夹
- 当前浏览器可能不支持 File System Access API。
- 解决方案：改用支持该能力的浏览器，或使用 Folia 桌面版。

**章节来源**
- [docs/local-library-management.md:57-58](file://docs/local-library-management.md#L57-L58)
- [docs/local-library-management.md:253-256](file://docs/local-library-management.md#L253-L256)

### 重启后无法播放本地歌曲
- 可能是浏览器或操作系统收回了目录读取权限。
- 解决方案：根据界面提示恢复本地音乐访问权限；若目录已移动或改名，重新导入该目录。

**章节来源**
- [docs/local-library-management.md:94-110](file://docs/local-library-management.md#L94-L110)
- [docs/local-library-management.md:257-259](file://docs/local-library-management.md#L257-L259)

### 自动匹配选错歌曲
- 自动匹配会优先使用网易云，再回退到 QQ 音乐和酷狗音乐。
- 解决方案：进入“整理歌曲信息”，修改检索文字并切换来源后手动选择候选；也可选择“使用本地信息”恢复导入快照。

- 检查默认端口：Web 为 `18080`，Sync Server 为 `13000`。
- 使用健康检查路径验证服务状态。

## 下一步建议
- 如果你只想快速听歌，优先选择桌面版或直接下载安装包。
- 如果你想长期自托管，优先使用 Docker Compose 全栈部署，并配置 HTTPS。
- 如果你需要在多设备间同步外观设置与 AI 主题，部署 Sync Server 并填写 `SYNC_TOKEN`。
- 如果你希望进一步定制本地音乐库，阅读本地音乐库管理文档，了解忽略规则、实体编辑、歌单导入导出等高级用法。
